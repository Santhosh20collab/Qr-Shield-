QR Shield Extension settings

Local engine

The extension talks to the QR Shield server running on this machine. Nothing is sent to a cloud service.

Start the server with python -m qrshield serve.

How to use it

  • Popup: paste a link, drop a screenshot, or choose a photo.
  • Right-click an image: choose “Scan image with QR Shield” to decode it in place.
  • Keyboard: Ctrl + Shift + Q opens the popup.

The extension downloads an image only when you explicitly ask it to scan that image. The QR Shield server itself never fetches a destination.

Permissions

  • Host access: needed to reach the local server and to read an image you right-click.
  • Clipboard: only when you press Paste.
  • Context menu: adds the image scan action.
  • Storage: remembers the API URL and the last result.
