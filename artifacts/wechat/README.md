# Optional WeChat QR models (better photo decoding)
#
# Download the four files from OpenCV's model zoo into this directory:
#   detect.prototxt  detect.caffemodel  sr.prototxt  sr.caffemodel
#
# https://github.com/opencv/opencv_zoo/tree/main/models/qrcode_wechatqrcode
#
# QR Shield detects them automatically and uses the WeChat decoder in addition
# to OpenCV's built-in detector. They are optional; everything works without.
